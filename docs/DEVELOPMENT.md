# Development

Use Windows x64 and the .NET 10 SDK selected by global.json. Visual Studio is optional. Git and PowerShell are enough; WSL is not required.

```powershell
./scripts/build.ps1 -Check -Package
```

The output is artifacts/Petal-win-x64.zip. Keep the executable and DLLs together. Downloaded models, personal history, SDK caches, test audio, and build outputs are excluded from Git.

## Tests

Petal.Checks contains nine deterministic suites for persistence, downloads, audio conversion, shortcuts, and search. Real-model tests download approximately 2.2 GB and require Internet access:

```powershell
dotnet run --project src/Petal.Checks -c Release -- models test-data whisper-tiny parakeet-v3 whisper-small whisper-turbo
dotnet run --project src/Petal.Checks -c Release -- stress test-data
```

App test modes use isolated data folders: --ui-smoke, --shortcut-smoke, --playback-smoke, and --integration-smoke. Each takes DATA_DIR OUTPUT_DIR. Integration mode briefly captures microphone audio and tests clipboard insertion into its own window. Do not point tests at personal app data.

## Screenshots

```powershell
./scripts/create-demo.ps1 -OutputDirectory .tools/demo-data
./artifacts/Petal-win-x64/Petal.exe --ui-smoke .tools/demo-data assets/readme/screenshots Dark
```

Demo content is fictional and audio is generated by Windows speech synthesis. An optional ModelDirectory points the isolated profile at an existing model cache. App-only WPF captures have no desktop background. DWM acrylic is represented by its opaque theme fallback in these exported images.

## Storage

Normal user data is in %LOCALAPPDATA%/Petal. Models and history are retained across portable app updates. Deleting the program folder does not delete recordings. Use Advanced to manage retained data.
